# TacticLens

AI match-intelligence engine on Azure that turns **synthetic** football events into explained,
personalized and accessible match storytelling.

Pipeline: Ingest -> Interpret -> Explain -> Render -> Personalize.

All clubs, players and matches are fictional and generated by our own simulator.

## Quick start (golden mode, no Azure needed)
```
py -3.11 -m venv .venv
.venv\Scripts\activate          # Windows  (source .venv/bin/activate on macOS/Linux)
pip install -e .[dev]
pytest -q
```

Regenerate the 6 golden matches and the realism report (`docs/realism.md`):
```
python -m tacticlens.sim all
```

Contracts live in `contracts/*.schema.json`; pydantic models in `src/tacticlens/contracts.py` mirror them.
